# Ad Creative Intel

## Purpose
从竞品广告库截图或链接中，拆解其 AI/UGC 广告的投放策略：创意格式、文案公式、测试节奏、放量信号，输出一份可直接指导己方创意生产的简报。

## Workflow

### 1. 收集证据
- 用户给截图：直接看。注意每张卡片上的：投放状态、开始投放日期、"N条广告使用这个创意和文字"（复用数）、平台图标、文案全文、视频/图片缩略图。
- 用户给链接：用 browser.open 打开 Facebook Ad Library 页面（公开，无需登录）。

### 2. 拆解四要素

**创意格式**：判断是真人 testimonial / AI 生成口播 / 产品特写 / 前后对比 / 开箱。记录视频时长、画幅、有无字幕。

**文案公式**：拆成钩子+痛点+成分/卖点+CTA 四段。特别注意：
- 钩子是否用"X天见效"类速度承诺
- 是否用"⭐⭐⭐⭐⭐ + 引用 + — 名字" 的伪评价格式
- 成分是否给具体百分比（建立专业感）

**测试方法论**：
- 总广告数 vs 去重后创意数 → 判断是广撒网还是精测
- "N条广告使用这个创意" 的复用数 → 复用数高的就是跑出来的 winners
- 开始投放日期跨度 → 跑了 3 个月以上还在投 =  profitable

**放量信号**：同一文案配多种视觉（视频版/图片版/多人口播版）= 在放量期做创意迭代。

### 4. 视频逐帧拆解（拿到 mp4 后）
用 ffprobe 确认时长/分辨率，再用 ffmpeg 按时长均分截 8 帧：
`ffmpeg -ss <t> -i <file> -frames:v 1 -vf "scale=180:-1" frame.jpg`
逐帧记录：画面内容、烧录字幕文字、场景切换点。提炼拍摄公式：
- **时长分层**：16s闪促 / 45-50s教育 / 90-110s深度种草
- **字幕规律**：是否每帧有烧录大字幕、关键词高亮色、是否直接喊话人群
- **结构弧线**：开头钩子（0-3s）→ 痛点/恐惧 → 产品登场 → 使用演示 → 结果/CTA
- **4种可迁移打法**：
  1. 闪促型：产品特写+全程紧迫感贴纸（BUY 1 GET 1 + 倒计时）
  2. 成分恐惧型：科普动画 scare 旧方案 → "AND NOW"转折 → 新品教程 → 定向人群结果
  3. 省钱对比型：生活化开场 → 旧方案贵/麻烦 → 产品效果 → 省钱省事
  4. 专家纠错型：画中画专家人设 → "N个错误"钩子 → 纠正误区演示 → 囤货CTA

### 5. 输出简报
按 `references/brief-template.md` 的格式输出：
- 一句话总结该品牌打法
- 可复刻的 3-5 条具体动作（格式、文案公式、测试节奏）
- 风险提示（平台政策红线，如前后对比图在 health 类目的限制）

## Operating Rules
1. 只基于可见证据推断，不编造投放金额、ROI 等不可见数据。
2. "跑得久=赚钱" 是启发式判断，如实标注为推测。
3. 涉及 health/beauty 类目前后对比、功效承诺时，必须提醒查 Meta 广告政策。
4. 简报默认中文，直接给结论。
